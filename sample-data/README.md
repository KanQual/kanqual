# Sample Data

`food-access-sample-project.json` is an importable Kanqual project backup.

To use it in the app:

1. Open `Projects`
2. Select `+ New Project`
3. Choose `Import Project`
4. Pick `sample-data/food-access-sample-project.json`

The sample project includes:

- 3 sample users that import as actual accounts
- 5 cases
- Case attributes for age, socioeconomic status, and neighborhood
- 5 documents
- Document attributes for interview date and interview format
- 12 codes
- 16 annotated segments

Note: Restoring a backup preserves project users and memberships. The currently signed-in user still remains the owner of the newly created restored project so they are never locked out of the restored copy.
